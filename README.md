# han-releases

Builds of **Han Themes** and **Han Auto** for the BYD Han (DiLink 5.0). The source code is private; this repo only hosts the APKs.

Han Auto checks the Releases here and updates itself and Han Themes automatically.
- Han Auto: tags `v<version>`, asset `HanAuto-v<version>.apk`
- Han Themes: tags `themes-<version>`, asset `HanThemes-<version>.apk`
